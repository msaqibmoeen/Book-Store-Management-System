# 📚 Book Store Management System

A complete MERN Stack (MongoDB, Express.js, React.js, Node.js) web application for managing books in a bookstore. This project allows users to add book details and store them in MongoDB using REST APIs. Users can also view all saved books in a modern and responsive interface.

---

# 🚀 Features

✅ Modern Responsive UI  
✅ Add New Books  
✅ View All Books  
✅ REST API Integration  
✅ MongoDB Database Connection  
✅ React Frontend  
✅ Node.js & Express Backend  
✅ Axios for API Requests  
✅ Attractive Card Design  
✅ Real-Time Data Fetching  
✅ Fully Responsive Layout
